LECCIÓN 1 DE 3

Módem, router y dispositivos

El módem enlaza la red local con el proveedor de Internet. El router conecta dispositivos entre sí y comparte la conexión, muchas veces mediante Wi-Fi.

  • Un punto de acceso emite la red inalámbrica.
  • SSID es el nombre visible de una red Wi-Fi.
  • Los dispositivos se conectan por cable Ethernet o por radio.
  • La velocidad depende del plan, distancia, interferencias y capacidad de los equipos.

Ejercicio 1

¿Qué equipo comparte la conexión entre los dispositivos de casa?

Ver una posible solución

El router conecta dispositivos y distribuye la conexión local.

Suele tener antenas o luces y puede incluir Wi-Fi.

2
LECCIÓN 2 DE 3

Resolver una conexión lenta o interrumpida

Aísla si el problema afecta a un dispositivo o a todos. Comprueba primero alimentación, cables y estado del servicio.

  1. Comprueba que el Wi-Fi está activado y el dispositivo conectado a la red correcta.
  2. Prueba otro dispositivo o cable Ethernet si está disponible.
  3. Revisa cables y luces del módem/router.
  4. Reinicia el router si es seguro interrumpir el servicio.
  5. Si falla en todos los equipos, contacta al proveedor.

Ejercicio 2

Si solo una computadora no conecta, ¿qué conviene comprobar primero?

Ver una posible solución

Que tenga Wi-Fi activado, use la red correcta y que otros dispositivos sí tengan conexión.

Confirma que use la red correcta y tenga Wi-Fi encendido.

3
LECCIÓN 3 DE 3

Proteger una red inalámbrica

Configura una contraseña robusta para el Wi-Fi y cambia la contraseña de administración predeterminada del router. Usa las opciones de seguridad actuales que permita el equipo.

  • Usa una clave larga y única para la red.
  • Actualiza firmware desde el fabricante del router.
  • Usa una red de invitados si está disponible.
  • No publiques la contraseña ni la dirección de administración.

Ejercicio 3

¿Qué credencial del router no debes dejar en su valor predeterminado?

Ver una posible solución

Cambia la contraseña de administración por una clave única; es distinta de la clave Wi-Fi.

Permite entrar a la configuración del router; no es la clave Wi-Fi.
