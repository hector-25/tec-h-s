01
LECCIÓN 1 DE 3

Armar un documento HTML

Las etiquetas marcan las partes del contenido. Un documento comienza con doctype, contiene metadatos en head y el contenido visible dentro de body.

<!doctype html>
<html lang="es">
  <head>
    <meta charset="utf-8">
    <title>Mi página</title>
  </head>
  <body>
    <h1>Hola, web</h1>
  </body>
</html>

Ejercicio 1

Crea un título principal para una página de presentación personal.

Ver una posible solución
<h1>Mi página personal</h1>

h1 identifica el encabezado principal y debe describir el tema de la página.

Es el encabezado de nivel uno.

02
LECCIÓN 2 DE 3

Conectar contenido

Los enlaces usan a para llevar a otro destino. Las imágenes usan img y deben incluir alt para describir la información visual.

<a href="https://example.com">
  Visitar el sitio
</a>

<img src="foto.jpg" alt="Montañas al amanecer">

Ejercicio 2

Crea un enlace a una página de Python con el texto “Aprender Python”.

Ver una posible solución
<a href="python.html">Aprender Python</a>

href guarda el destino del enlace; el texto entre etiquetas explica a dónde lleva.

Aparece en la etiqueta de apertura a.

03
LECCIÓN 3 DE 3

Recoger información con formularios

Las listas ordenadas y sin ordenar agrupan elementos. Los formularios reúnen controles para que la persona introduzca información.

<form>
  <label for="correo">Correo</label>
  <input id="correo" type="email" required>
  <button type="submit">Enviar</button>
</form>

Ejercicio 3

Añade un campo para nombre y una etiqueta vinculada al campo.

Ver una posible solución
<label for="nombre">Nombre</label>
<input id="nombre" name="nombre" required>

for e id deben coincidir para asociar la etiqueta con el campo.

El nombre es igual que la palabra en inglés para formulario.
