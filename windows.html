LECCIÓN 1 DE 3

Escritorio, menú Inicio y Explorador

El escritorio es el espacio de trabajo. El menú Inicio permite abrir aplicaciones y Configuración. El Explorador de archivos organiza carpetas y unidades.

  • Usa búsqueda del menú Inicio para localizar una aplicación.
  • Fija en Acceso rápido las carpetas frecuentes.
  • Aprende a reconocer rutas como Documentos/Proyecto.
  • Extensiones como .pdf o .jpg ayudan a identificar formatos.

Ejercicio 1

¿Qué herramienta de Windows sirve para ver unidades, carpetas y archivos?

Ver una posible solución

El Explorador de archivos, que puedes abrir desde la barra de tareas o Inicio.

Su icono suele parecer una carpeta.

2
LECCIÓN 2 DE 3

Organizar documentos y respaldos

Crea carpetas con nombres claros y guarda copias importantes en otra ubicación. La sincronización en la nube ayuda, pero no sustituye siempre una copia separada.

  1. Crea carpetas por proyecto o año.
  2. Usa nombres descriptivos y evita duplicados.
  3. Haz copias en una unidad externa o servicio confiable.
  4. Comprueba que puedes abrir la copia.

Ejercicio 2

¿Cómo se llama una copia adicional de tus archivos para recuperarlos si se pierden?

Ver una posible solución

Una copia de seguridad o respaldo.

También se conoce por la palabra backup.

3
LECCIÓN 3 DE 3

Configuración, actualizaciones y recuperación

Windows Update ofrece actualizaciones del sistema. Guarda tu trabajo y sigue las indicaciones antes de reiniciar. Antes de reinstalar, respalda archivos y confirma que tienes tus credenciales.

  1. Abre Configuración y busca Windows Update.
  2. Selecciona buscar actualizaciones y revisa la propuesta.
  3. Instala desde Windows Update o herramientas oficiales de Microsoft.
  4. Antes de restablecer o reinstalar, realiza respaldo; algunas opciones pueden quitar archivos o aplicaciones.
Instalación: descarga medios solo de Microsoft. Un USB puede borrarse al prepararlo y una instalación limpia puede eliminar datos del disco seleccionado.
