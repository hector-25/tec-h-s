LECCIÓN INICIAL

Tu primera función en JavaScript

Una función agrupa instrucciones bajo un nombre para poder usarlas cuando las necesites.

CONCEPTO CLAVE

¿Qué es una función?

Una función recibe información, ejecuta instrucciones y puede devolver un resultado. Separar una tarea en funciones ayuda a que el programa sea más fácil de leer, probar y cambiar.

Idea para recordar: usa nombres que describan la acción, como calcularTotal o saludar.
function saludar(nombre) {
  return "¡Hola, " + nombre + "!";
}

saludar("Ana"); // "¡Hola, Ana!"
PRUEBA ESTO

Tu primer ejercicio

Personaliza la función para que genere un saludo para quien visita Tec-H-S.

  • Cambia el nombre por una variable.
  • Prueba con un segundo nombre.
  • Añade un mensaje de bienvenida.
function bienvenida(nombre) {
  return "Bienvenido/a, " + nombre;
}

bienvenida("Alex");
