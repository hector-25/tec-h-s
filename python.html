01
LECCIÓN 1 DE 3

Tu primer programa

print() muestra información en la consola. Las variables guardan valores para volver a usarlos. Python reconoce números, texto y valores verdaderos o falsos.

print("Hola, mundo")

nombre = "Alex"
print("Hola,", nombre)

Ejercicio 1

Escribe una línea de Python que muestre el texto Tec-H-S.

Ver una posible solución
print("Tec-H-S")

print() recibe el texto entre comillas y lo muestra en la consola.

Su nombre en inglés significa imprimir.

02
LECCIÓN 2 DE 3

Recibir datos y tomar decisiones

input() lee texto que escribe una persona. if y else permiten elegir qué instrucciones ejecutar según una condición.

nombre = input("¿Cómo te llamas? ")

if nombre:
    print("¡Hola,", nombre, "!")
else:
    print("Escribe tu nombre para continuar.")

Ejercicio 2

Pide la edad y muestra un mensaje distinto si es mayor o menor de 18.

Ver una posible solución
edad = int(input("Edad: "))

if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")

int() convierte el texto de input() a número entero para poder compararlo.

Se usa en la línea donde aparece la pregunta entre paréntesis.

03
LECCIÓN 3 DE 3

Bucles, listas y funciones

for repite una acción por cada elemento de una secuencia. Una lista guarda varios valores y una función agrupa instrucciones que puedes reutilizar.

def saludar(nombre):
    return "Hola, " + nombre

for persona in ["Ana", "Luis"]:
    print(saludar(persona))

Ejercicio 3

Completa el reto para que el programa repita un saludo para cada nombre de la lista.

Ver una posible solución
nombres = ["Ana", "Luis", "Mia"]

for nombre in nombres:
    print("Hola,", nombre)

for toma un elemento por vuelta y ejecuta el bloque indentado.

Aparece en el ejemplo de la lección anterior y se traduce como “si”.
