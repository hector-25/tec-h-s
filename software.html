LECCIÓN 1 DE 3

Sistema operativo, aplicaciones y controladores

El sistema operativo administra el equipo y ofrece servicios a las aplicaciones. Los controladores ayudan al sistema a comunicarse con dispositivos como impresoras o tarjetas gráficas.

  • Sistema operativo: administra archivos, memoria, dispositivos y cuentas.
  • Aplicación: sirve para una tarea, como escribir o editar fotos.
  • Controlador: permite que el sistema use correctamente un dispositivo.

Ejercicio 1

¿Qué tipo de software administra memoria, archivos y dispositivos?

Ver una posible solución

El sistema operativo, como Windows, macOS o una distribución de Linux.

Es el primer software que carga al iniciar y permite abrir aplicaciones.

2
LECCIÓN 2 DE 3

Instalar programas de fuentes confiables

Descarga el instalador desde la web oficial del fabricante o una tienda reconocida. Verifica el nombre de la aplicación y evita anuncios de descarga engañosos.

  1. Confirma qué sistema operativo usa tu equipo.
  2. Busca la página oficial del fabricante o usa la tienda integrada del sistema.
  3. Lee los requisitos, permisos y condiciones de licencia.
  4. Durante la instalación, revisa cada opción y rechaza extras que no solicitaste.
Evita: activadores y sitios que prometen licencias gratuitas; pueden infringir licencias o instalar malware.

Ejercicio 2

Debes instalar un lector PDF. ¿Cuál es el lugar más seguro para buscarlo?

Ver una posible solución

La página oficial del desarrollador o una tienda de aplicaciones confiable. Comprueba el dominio y el nombre del producto.

Debe ser la página auténtica del fabricante o la tienda del sistema.

3
LECCIÓN 3 DE 3

Actualizar y desinstalar

Las actualizaciones corrigen errores, añaden funciones y a menudo incluyen mejoras de seguridad. Desinstala programas que ya no necesitas usando las herramientas del sistema.

  • Activa actualizaciones automáticas cuando sea posible.
  • Reinicia si el instalador lo solicita y guarda tu trabajo primero.
  • Si una app no funciona, busca ayuda oficial.
  • Desinstala desde Configuración o la tienda.

Ejercicio 3

Una aplicación tiene una actualización de seguridad. ¿Qué conviene hacer?

Ver una posible solución

Verifica que el aviso provenga de la aplicación legítima y actualízala desde su sitio o mecanismo oficial.

Mantiene el programa al día.
