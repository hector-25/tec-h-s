01
LECCIÓN 1 DE 3

Escribir tu primera regla

Una regla CSS combina un selector con una o más declaraciones. Cada declaración asigna un valor a una propiedad.

h1 {
  color: #3984ff;
  font-size: 2rem;
}

Ejercicio 1

Cambia el color de todos los párrafos a azul.

Ver una posible solución
p {
  color: blue;
}

El selector p apunta a todos los párrafos; color define el color del texto.

Se ve a la izquierda de #3984ff en el ejemplo.

02
LECCIÓN 2 DE 3

Entender el modelo de caja

Cada elemento ocupa una caja. El contenido está rodeado por padding interno, un borde y margin exterior que separa elementos.

.card {
  padding: 20px;
  border: 1px solid #334;
  margin: 12px;
}

Ejercicio 2

Añade espacio dentro de una tarjeta sin aumentar el espacio exterior.

Ver una posible solución
.card {
  padding: 16px;
}

padding crea espacio entre el contenido y el borde; margin separa la caja de los demás elementos.

No es margin: está en el interior de la caja.

03
LECCIÓN 3 DE 3

Alinear elementos con Flexbox

Flexbox distribuye elementos dentro de un contenedor. Las consultas de medios permiten cambiar el diseño según el ancho de la pantalla.

.menu {
  display: flex;
  gap: 16px;
}

@media (max-width: 600px) {
  .menu { flex-direction: column; }
}

Ejercicio 3

Haz que los elementos de .fila se distribuyan en una fila con Flexbox.

Ver una posible solución
.fila {
  display: flex;
  gap: 12px;
}

display:flex convierte el elemento en contenedor flexible para sus hijos.

La declaración empieza con display: y su valor es flex.
