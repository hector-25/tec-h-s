LECCIÓN 1 DE 3

Linux, distribuciones y escritorio

Linux suele referirse al kernel; una distribución lo combina con herramientas, aplicaciones y un método de actualización para formar un sistema instalable.

  • Ubuntu es una distribución de Linux.
  • El escritorio ofrece ventanas, menús y aplicaciones.
  • Hay distribuciones con distintos diseños y ciclos de soporte.
  • Prueba primero una sesión en vivo o una máquina virtual si estás aprendiendo.

LECCIÓN 2 DE 3

Primeros pasos en la terminal

La terminal permite pedir tareas al sistema escribiendo comandos. Empieza con comandos que solo muestran información y comprueba la ruta antes de modificar archivos.

pwd   # muestra la carpeta actual
ls    # lista archivos y carpetas
cd Documents   # entra a una carpeta
Prudencia: evita copiar comandos con sudo o instrucciones para borrar discos si no entiendes qué hacen.

LECCIÓN 3 DE 3

Probar Ubuntu e instalar desde la fuente oficial

Puedes descargar una imagen oficial, crear un USB de prueba y revisar si funciona el hardware antes de instalar. La elección del disco durante una instalación es crítica.

  1. Consulta requisitos y descarga desde ubuntu.com.
  2. Sigue las instrucciones oficiales para crear el USB.
  3. Prueba el escritorio en vivo o una máquina virtual antes de cambiar el sistema principal.
  4. Haz respaldo y confirma qué disco y partición seleccionaste.
  5. Si seleccionas borrar disco, se eliminarán los datos de esa unidad. No continúes si no estás seguro.
