01
LECCIÓN 1 DE 3

Mostrar información

console.log() muestra mensajes en las herramientas del navegador. const crea una referencia que no se reasigna y let permite cambiar su valor.

const nombre = "Alex";
let visitas = 1;

console.log("Hola, " + nombre);
visitas = visitas + 1;

Ejercicio 1

Guarda tu nombre en una constante y muéstralo con console.log().

Ver una posible solución
const nombre = "Sam";
console.log(nombre);

El nombre se asigna a const y luego se pasa a console.log().

Es un método de console que vimos al inicio.

02
LECCIÓN 2 DE 3

Tomar decisiones y repetir

if ejecuta un bloque cuando una condición se cumple. Un bucle for repite instrucciones un número de veces o recorre una colección.

const puntaje = 82;

if (puntaje >= 70) {
  console.log("Aprobado");
} else {
  console.log("Sigue practicando");
}

Ejercicio 2

Escribe una condición que revise si una temperatura es menor que 10.

Ver una posible solución
const temperatura = 8;

if (temperatura < 10) {
  console.log("Hace frío");
}

El bloque dentro de if se ejecuta cuando la comparación es verdadera.

En inglés significa “si”.

03
LECCIÓN 3 DE 3

Crear interacciones

Una función agrupa código reutilizable. Los eventos permiten ejecutar una función cuando ocurre algo, por ejemplo, al hacer clic en un botón.

function saludar() {
  console.log("¡Hola!");
}

document.querySelector("button")
  .addEventListener("click", saludar);

Ejercicio 3

Añade un evento para que un botón muestre “¡Bienvenido!” al hacer clic.

Ver una posible solución
function mostrarMensaje() {
  alert("¡Bienvenido!");
}

document.querySelector("button")
  .addEventListener("click", mostrarMensaje);

addEventListener conecta el evento click con la función que responde a ese evento.

Se usa después de seleccionar un botón y antes de indicar el evento click.
