LECCIÓN INICIAL

Tu primera consulta SQL

SELECT elige columnas y FROM indica la tabla de la que se leen los registros.

CONCEPTO CLAVE

Consultar sin cambiar los datos

Una consulta SELECT recupera información. WHERE filtra los resultados; ORDER BY los ordena. Empezar consultando permite explorar una tabla antes de realizar cambios.

Idea para recordar: especifica las columnas que necesitas y usa filtros claros para obtener resultados útiles.
SELECT nombre, ciudad
FROM estudiantes
WHERE ciudad = 'Quito'
ORDER BY nombre;
PRUEBA ESTO

Tu primer ejercicio

Consulta una tabla de cursos para encontrar los cursos gratuitos y ordenarlos por nombre.

  • Elige solo las columnas título y nivel.
  • Filtra los registros gratuitos.
  • Ordena los resultados alfabéticamente.
SELECT titulo, nivel
FROM cursos
WHERE gratuito = TRUE
ORDER BY titulo;
